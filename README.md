# 漫序 · 本地漫剧制作工作台

这是一个可以在浏览器里制作并导出简单动态漫剧的单页工具。GitHub Pages 负责发布页面，图片和配音素材留在打开网站的这台设备上。

## 实际可用功能

- 编辑故事并按句子拆分分镜，逐镜调整标题、画面描述、对白、角色、运镜和时长
- 给每个镜头上传图片，并上传该镜头对应的配音音频
- 浏览器朗读可试听对白；它不会自动生成音频，也不会进入导出视频
- 将分镜图片、镜头文字、对白字幕和已上传音频合成为视频文件
- 图片与配音素材保存在当前浏览器的本机存储；下载项目备份时会将图片和可读取的配音一并打包

## 导出说明

点击右侧“合成并下载 WebM 视频”。视频为 1280×720；每张静态图会按镜头运镜做轻微缩放或横移，并叠加对白字幕。配音按镜头起始时间播放，超出镜头时长的部分会截断。没有上传音频的镜头会保持静音。浏览器支持 MP4 录制时会输出 MP4，否则输出 WebM。

推荐使用最新版 Chrome 或 Edge，并保持页面在前台直到导出结束。不同设备的浏览器对视频和音频编码支持不同。若页面提示浏览器不支持录制，请换用 Chrome 或 Edge。

## 当前范围

这是素材合成器，不会自动生成故事、AI 分镜画面或可下载配音。画面和配音需要由创作者准备并逐镜上传。作品只在本地浏览器处理，不会上传到服务器。音频素材存放在浏览器 IndexedDB；浏览器清理站点数据后素材会丢失，请先下载项目备份。项目 JSON 带音频时可能较大。

## 发布

项目不需要构建步骤。推送到 `main` 后，仓库中的 GitHub Actions 工作流会发布到 GitHub Pages。仓库的 Pages Source 需要设为 **GitHub Actions**。网站源码及网页会按 GitHub Pages 公开仓库的设置公开访问；不要将 API 密钥或私人素材放入仓库。
