# 漫序 · AI 漫剧工作台

这是一个可直接静态托管的单页本地创作工具，入口为 `index.html`。

## 当前可用功能

- 编辑故事脚本，并按句子拆成分镜
- 编辑每个镜头的标题、画面描述、对白、角色、运镜和时长
- 为单个镜头上传图片，也可以批量按顺序导入
- 使用浏览器内置语音朗读对白，可切换设备提供的中文音色与语速
- 通过浏览器本地存储自动保存项目
- 下载 JSON 项目文件，并在另一台设备导入

脚本拆镜使用本地规则，不调用大语言模型。图片由用户提供。浏览器语音只负责朗读和试听，不会生成可下载音频；当前也不导出 MP4。

## 本地预览

直接用浏览器打开 `index.html`。建议使用最新版 Chrome 或 Edge，以获得浏览器语音合成支持。

## 发布

项目不需要构建步骤。仓库已带 GitHub Actions 工作流：推送到 `main` 后会自动发布到 GitHub Pages。

在 GitHub 仓库的 **Settings → Pages** 中将 Source 设为 **GitHub Actions**。首次部署后，Actions 会提供站点地址。

注意：GitHub Pages 网站是公开可访问的。GitHub Free 个人账号需要使用公开仓库；如果仓库设为私有，需要支持私有 Pages 的付费计划。不要在该仓库中放 API 密钥或私人素材。
